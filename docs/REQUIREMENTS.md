# Requisitos do Projeto - SmartMarket

Este documento descreve as funcionalidades e requisitos técnicos do SmartMarket.

## 🎯 Objetivo
Transformar a experiência de compra em supermercados através de encartes digitais interativos e geolocalizados.

## 🚀 Funcionalidades (MVP)

### 🏬 Gestão do Supermercado (Manager)
- **Identidade Visual**: Personalização de cores (Primária/Secundária) e upload de logotipo.
- **Encartes Digitais**:
    - Criação de encartes temáticos (Natal, Black Friday, etc.).
    - Seleção de ofertas em tempo real.
    - Busca e filtragem de produtos.
    - Preview imersivo (Smartphone Mockup).
- **Publicação**: Gerar link público para compartilhamento via WhatsApp/Redes Sociais.

### 👥 Visão do Cliente (Consumidor)
- **Visualizador de Encarte**:
    - Layout de tabloide responsivo (1-4 colunas).
    - Selos de preço de varejo clássicos.
    - Informações de contato da loja e validade.
- **Lista de Compras**: Adicionar produtos do encarte diretamente a uma lista (simulado).

## 🛠️ Requisitos Não Funcionais
- **Performance**: Tempo de carregamento do encarte digital inferior a 2 segundos em conexões 4G.
- **Escalabilidade**: Arquitetura baseada em microserviços e frontend modular.
- **Whitelabel**: Suporte a múltiplos supermercados com identidades visuais distintas.
- **Mobile-First**: Interface totalmente otimizada para smartphones.

## 🗺️ Roadmap (Próximas Fases)
- [ ] Notificações Push baseadas em geolocalização.
- [ ] Integração com PDV para atualização automática de preços.
- [ ] Analytics de visualizações e intenção de compra.
- [ ] IA para recomendação personalizada de ofertas.
